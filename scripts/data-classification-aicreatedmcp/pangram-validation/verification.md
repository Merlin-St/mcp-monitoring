# Cross-Validation: Pangram API vs. Git Commit Evidence

## Validation Summary

We cross-validated our commit-mining AI detection approach (Agent 2) against Pangram's commercial AI content detection API (v3) on a subset of 197 MCP server repositories with valid Pangram scores (3 of 200 API calls returned null results due to credit exhaustion). Pangram analyses README content only (not source code or commit history) and returns: `fraction_ai` (fraction of text classified as AI-generated, 0.0--1.0), `fraction_ai_assisted` (fraction classified as AI-assisted, 0.0--1.0), `fraction_human` (fraction classified as human-written, 0.0--1.0), a `headline` prediction (e.g., "Fully AI Generated", "AI Detected", "Fully Human Written"), and a `prediction` string providing a detailed classification explanation. Agent 2 analyses the full paginated commit history (up to 10,000 commits per repository), pull request metadata, repository file tree, and contributor accounts, classifying each server with a binary `ai_authored` label ("yes" or "no") based on four criteria: (1) presence of Co-Authored-By trailers referencing AI tools, (2) AI configuration files (e.g., CLAUDE.md, .cursor/, .github/copilot-instructions.md), (3) AI bot contributors, and (4) at least one AI tool handle mention in commits or PRs.

The two methods measure fundamentally different constructs: Pangram detects whether the *documentation text* was AI-authored, while the commit-mining approach detects whether *AI coding agents* were used in the development process (via Co-Authored-By headers, AI configuration files, bot contributor accounts, and AI tool references in commit messages and pull requests). Pangram classified 76 of 197 repositories (38.6%) as "Fully AI Generated" (fraction_ai >= 0.9), 51 (25.9%) as "AI Detected" (fraction_ai between 0.5--0.9), 13 (6.6%) as "Mostly Human, AI Detected", and 57 (28.9%) as "Fully Human Written" or "Mostly Human Written" (fraction_ai < 0.3); the mean fraction_ai was 0.57 (median 0.67), with negligible AI-assisted content (mean fraction_ai_assisted = 0.003). Agent 2, on the 197-server overlap, classified 55 (27.9%) as `ai_authored = "yes"`, scanning 11,138 total commits (18 repositories with >100 commits) and identifying Claude as the dominant tool (33 of 55 repositories with a detected tool, 60.0%), followed by Copilot (10, 18.2%) and Cursor (7, 12.7%). The most common triggering criteria were AI handle mentions (37 repos), configuration files (27), and Co-Authored-By lines (26).

Using a binary classification threshold (Pangram: fraction_ai >= 0.8 as "AI-written"; Agent 2: ai_authored = "yes"), overall agreement is 53.3% (n = 197): both methods concur on 24 repositories as AI-involved (12.2%) and 81 as human-only (41.1%). The primary source of disagreement is 61 repositories (31.0%) where Pangram detects AI-generated README content but commit history shows no AI coding agent evidence -- consistent with widespread use of conversational AI (e.g., ChatGPT, Claude chat) for documentation drafting without adoption of agentic coding tools that leave commit-level traces. 31 repositories (15.7%) show the reverse pattern (commit evidence without Pangram detection), suggesting that AI coding agents sometimes produce documentation that Pangram classifies as human-like. At the 0.8 threshold, Pangram classifies 85 of 197 repositories (43.1%) as AI-written. This asymmetry supports treating the two approaches as complementary rather than redundant: Pangram captures AI-generated *content* (particularly documentation), while commit mining captures AI-assisted *development process*, and their union provides a more complete picture of AI involvement in MCP server creation.
